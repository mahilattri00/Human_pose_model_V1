# HUMANSENSE AI Models Directory

Place the YOLO26n-Pose PyTorch weights file here:

`models/yolo26n-pose.pt`

### Model Details
- Model: YOLO26n-Pose (Ultralytics YOLO Pose Nano)
- Keypoints: 17 standard COCO body keypoints
- Framework: Ultralytics PyTorch

If this file is missing when starting with camera capture, the application will display a clear error message and guide you to place the model file here or use DEMO MODE.
